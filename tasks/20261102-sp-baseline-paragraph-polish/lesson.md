# §4.2 S-P Baseline Paragraph Polish — Lessons

## 2026-11-02

- **Read each manifest field's definition before quoting it.** `wrong_adjacent_pct` (88%)
  is the share in an *adjacent* cell, not "in other cells".
- **A pooled median can hide a per-network reversal.** Nearest VP for no-X vs has-X is
  3.6 vs 3.0 pooled, but 15.8 vs 3.7 in AS-B. The draft keeps the pooled claim. If a
  reviewer splits by network, add the per-network numbers.
- **Separate what the claim needs from what the figure measures.** has-X is a cell property
  (the cell holds an interconnect), so "S-P cannot be right on no-X" needs no estimate of X_in.
  The nearest interconnect is only the reference for *where* answers land (Fig. 5b, 85%).
  Writing it as "we take nearest X as X_in" created a loop with "S-P finds the real X_in".
