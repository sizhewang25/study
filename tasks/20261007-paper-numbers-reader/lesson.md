# Paper Numbers Reader — Lessons

## 2026-10-07

- The user wants to confirm the statistics section by section before any code is written.
  Present one section's inventory at a time and wait for the user to confirm it.
- The reader must not assume the paper project is checked out beside the framework. It
  reports statistics only, and comparing them with the paper is the user's step.
- Report data, not sentences: one table per paper figure/table, absolute values and percentages
  only, no × ratios. The user rewrites the text and compares it against the tables.
